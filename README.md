## Download

Grab the current `.kwgt` files / complete pack from the **[Releases](https://github.com/BirdMachine/TimeCrystals-KWGT/releases)** page.

Release assets are used for the downloadable widget files so the repository itself can stay lightweight while still providing the original full-quality presets.

## Installing in KWGT

1. Download the `.kwgt` preset you want from **Releases**.
2. Open **KWGT**.
3. Import the downloaded preset.
4. Add a KWGT widget to your launcher and select the imported TimeCrystals preset.
5. Resize/tweak to taste — subtlety is not really the assignment here. 💎

## Notes

These presets are intended for **Kustom Widget Maker (KWGT)**. Depending on your KWGT setup/version, importing third-party presets may require **KWGT Pro**.
